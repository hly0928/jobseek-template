# CV and evidence

Before starting, add the immutable base CV as:

`CV/CV_Plain_Base.docx`

Optional master variants may be placed in `CV/Masters/`. Put only an index and safe supporting evidence in `CV/Evidence/`; identity, banking, tax, medical and other highly sensitive documents must not be automatically uploaded.

The base CV is authoritative and must remain truthful. Tailored CVs are generated per eligible role and never overwrite it.
