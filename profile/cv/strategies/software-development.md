# Software Development CV Strategy

Guidance only - not a candidate fact source.

- Use only facts and evidence present in the frozen base CV, candidate profile, track profile and approved banks.
- Lead with relevant programming, web/API, database, testing and project-delivery evidence.
- Order projects to match the advertisement's stack and duties; normally prioritise collaborative application projects before documentation, infrastructure or research evidence.
- Emphasise implemented features, integration, testing, debugging, version-control collaboration and documentation only when the frozen sources support them.
- Describe Docker, deployment, CI/CD and configuration work as project-level evidence unless a frozen fact source establishes a stronger context.
- Compress unrelated administration, research or support content. Keep it only when it demonstrates a requirement such as analysis, stakeholder communication or documentation.
