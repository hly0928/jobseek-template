# Job Track

Rename `JobName` to the chosen track and update only the track key and matching
`input_paths` in `.jobseek/config.json`. Do not modify script constants.

Authoritative track inputs:

- `Profile/Track_Profile.md`
- `Templates/Search_Criteria.md`
- `Templates/Application_Answer_Overrides.md`

`Tracker/` and `Logs/` are legacy compatibility/history views, not lossless
batch exports.
`Applications/` contains only directly confirmed submissions.
